## **Caterpillar Auger Alignment System - CAAS (Senior Design) - Fall 2025/Spring 2026**

**Details:** Designed a multilayer KiCad PCB integrating ESP32s with high-precision IMU and power management; architected the full hardware solution (from schematic capture through PCB layout) and developed C firmware to process inertial data and provide real-time orientation via ESP-Now and an LED interface for precise field alignment. The project included prototyping, system integration, hardware and software testing (including embedded-system validation), and iterative fixes to mature design.
**Tech:** KiCad, C, ESP32, ESP-NOW, PCB Design, IMU Sensors
